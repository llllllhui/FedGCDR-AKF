# 动态知识融合实现与运行

## 实现与原论文的关系

上游地址：https://github.com/LafinHana/FedGCDR 。固定提交为 `09c63ef5b36903dfbadee86b31aabdcee7f98205`。`upstream/FedGCDR/` 保留原文件和全部 22 条提交记录，采用部分克隆；旧版本 blob 在需要时联网获取。所有当前跟踪文件的 SHA-256 记录于 `upstream/source_manifest.json`。

`research/fedgcdr_akf/upstream.py` 直接加载上游 GAT、GATLayer、MLP，没有修改上游实现。研究入口重写数据处理及训练编排，避免上游入口的数据缺失、设备硬编码和训练/测试分离不足等问题。`graph_transfer` 是使用这些上游模块的协议适配对照，不能标作原始 FedGCDR 的精确复现。FR-CSU 融合是按本项目已确认的候选设计实现，尚未取得其官方代码。

## 数据协议

1. 用 Python 标准库流式读取无表头四列 CSV，将评分不低于配置阈值的行为作为正反馈，写入输出目录的 SQLite。重复用户物品对保留最早的正反馈时间。
2. 在目标域去重正反馈上计算配置比例的全局时间截点。所有域训练行为时间均不晚于目标域训练截点；源域未来行为不进入知识或统计。
3. 只按目标域训练交互数量筛选用户，以种子与原始用户标识的哈希顺序进行可重复截取；用户群选定后，源域只保留该用户群。这是当前试验的数据协议，未利用验证或测试效果筛选用户。
4. 每个域的物品表只来自该用户群的训练交互。目标验证、测试仅保留已知用户和训练物品表内的正反馈，报告因未见物品丢弃的交互及可评估用户数。
5. 输入摘要记录读取行数、字节数、文件大小和 SHA-256。有限行数模式的哈希只覆盖实际读取的文件头，不能冒充整文件哈希。`max_rows_per_domain=0` 表示读取全文件，`max_users=0` 表示保留所有满足训练历史要求的目标用户。

数据来源与跨品类用户标识语义仍待独立核验。当前有界文件头样本存在物品顺序偏差，不构成正式基准。SQLite 导入可以流式处理；选定用户群的交互及物品表随后载入内存，扩大到全部用户前仍须评估内存和磁盘预算。正式协议还需决定是否纳入源域独有用户。

## 模型与训练

- 每个域先用训练交互进行用户客户端的本地图训练，复用上游双层 GAT。源知识取训练后 GAT 第一层的用户表示，与上游知识位置一致；提取后冻结，验证/测试不更新源知识。
- 目标训练复用上游 MLP 将各个可用源域表示映射到目标空间，将这些表示加入目标 GAT 的第二层图；保留上游对齐正则项。没有源知识的域不添加零向量节点，避免映射层偏置产生虚假知识。
- 独立本地分支为本地用户向量与物品向量的内积；迁移分支由 `f1(concat(扩展图用户向量, 物品向量))` 输出。融合为 `f2(local_score + gamma * transferred_score)`。
- 用户级 gamma 输入本地用户向量、扩展图用户向量及训练交互数的对数；物品条件 gamma 再加入候选物品向量。gamma 经 sigmoid 约束到 `[0,1]`。这是加性迁移强度，非凸组合系数。当前单次运行只训练一个目标域模型，尚未实现跨目标域共享门控。
- 所有源知识缺失时，融合方法直接回退为本地内积并返回 gamma=0；`graph_transfer` 仍可使用目标域本地图。
- 显式设置固定 gamma=0 只关闭预测中的迁移项，图对齐正则仍存在；若要完全移除跨域训练影响，应使用 `local` 对照或另做正则消融，不将这两者混同。
- 训练负样本从训练物品表中抽取，排除该用户的训练正反馈，不查看验证或测试标签。重复抽样允许；目录全部被该用户交互时，不抽取负样本。

## 联邦模拟与资源

初始实现按上游组织为用户客户端和域服务器，单机进程模拟全部客户端。每批客户端从同一份共享模块和物品快照进行本地 Adam 更新；共享模块按本地训练交互数量加权平均，物品行按实际参与更新的客户端平均。用户向量更新保留在模拟客户端状态，不参与用户间平均。只复制客户端触及的物品行，GAT 邻居和每轮正样本数量有显式上限。

研究入口用较小的对称区间初始化表示，而未照搬上游的 `[0,1]` 初始化；重置每批客户端的本地优化器，以最终聚合模块重新提取源知识。邻居截取、训练负采样、源域缺失掩码、去重物品行更新及独立验证集均属于显式协议适配。

该模拟器的数据准备仍在同一进程可访问的本地文件中，尚无真实设备隔离、安全聚合、DP 噪声或隐私会计，不宣称继承原论文的隐私保证。通信量是活跃共享参数、触及物品行和行索引的概念性双向载荷估计，另列一次源知识向量传输量，不包含真实网络、身份匹配、安全协议和序列化开销。

## 已实现对照

| 模式 | 行为 |
| --- | --- |
| `local` | 目标域本地预测；只用目标域训练信息 |
| `graph_transfer` | 上游图扩展模块的适配对照，直接图用户/物品内积 |
| `fixed` | 固定 gamma；可用 fixed_gamma_candidates 在验证集搜索，未指定时取 fixed_gamma |
| `fixed_capacity` | 固定 gamma，扩大迁移预测层，使共享参数量接近用户级门控模型 |
| `global` | 所有具备源知识的用户共享一个可学习 gamma |
| `user` | 根据用户及训练信息生成 gamma；同一用户的 gamma 不随候选物品改变 |
| `item` | gamma 还依赖候选物品 |

融合方法共享预训练状态，重置共同模块的初始化种子和训练采样种子。容量匹配是近似值，汇总中记录活跃共享参数数；物品条件模型与用户级模型的参数预算不完全相同。所有模式都保留在预先配置的比较表中，不根据测试结果隐藏方法。

## 评估与产物

每轮仅在验证集上评估，以 NDCG@10、再以 Recall@10 选择模型；并列时保留较早轮次。选定检查点后，每个预先声明的方法仅执行一次最终测试。候选为目标域完整训练物品表，屏蔽用户训练正反馈，计算多正反馈 Recall@10 和 NDCG@10，而非固定 99 个负例。

可选配置 `training.fixed_gamma_candidates` 对 fixed 与 fixed_capacity 分别执行验证集搜索。所有权重候选从共同预训练状态、初始化种子和采样种子开始，全部候选完成后才执行一次该方法的最终测试；并列时保留先出现的候选和轮次。检查点记录实际选中的 `selected_fixed_gamma`，恢复固定权重模型时需使用该值。汇总区分选中候选的通信量估计和全部搜索的总通信量、耗时。

`scripts/local_comparison.py` 在相同 prepared.json 上运行配置中的多个训练种子，并保留所有控制台日志与失败状态。`comparison.py` 核验验证选模及测试次数，生成聚合 Markdown、CSV 和 JSON。具体本地比较见 `local_comparison_protocol.md`；均值与样本标准差描述本轮种子变化，不替代正式统计结论。

报告整体、按训练交互数分组的结果及逐用户相对本地/固定权重基线的指标变化。门控诊断另外在训练用户及训练物品表上进行，只统计有源知识的用户，避免把缺失知识时的 gamma=0 误读成动态学习。门控变化与预测效果是两类证据。

运行方法见根目录 README。数据输出目录包含：

- `interactions.sqlite`：本次读取的数据及去重记录。
- `prepared.json`：本地用户/物品映射及训练、验证、测试划分。
- `summary.json`：输入哈希、截点、用户群及覆盖率。

训练输出目录包含：

- `config.json`、`history.jsonl`：完整配置及分阶段日志。
- `pretrained.pt`：冻结源知识、可用性掩码和目标预训练状态。
- `<mode>.pt`：根据验证集选择的共享模块、本地用户向量、图用户向量及物品向量。
- `<mode>_test_users.json`：本地用户索引的逐用户结果。
- `summary.json`：环境、来源、配置、数据哈希、全部方法指标及耗时。

数据与完整运行目录不纳入版本控制。`results/` 只保存聚合验证结果，不保存原始用户标识或检查点。

## 后续正式实验

仍需数据来源核验与全量重叠审计、确定正式域组合和用户群、验证集超参数搜索、多随机种子、门控输入消融、独立的上游协议复现与隐私方案。当前运行只验证实现能够完成整个流程，不能据此声称动态权重优于固定权重。
