# 本地小规模对比试验协议

预先确定日期：2026-10-28。目标是比较已有动态融合实现，保留全部方法与全部种子结果，不以测试效果追加调参。

- 数据：Movies_and_TV 为目标域，Books、CDs_and_Vinyl 为源域；每域读取前 1,000,000 行，评分至少 4 为正反馈，重复对保留最早正反馈。
- 用户群：训练正反馈至少 3 条，固定数据种子 2026，通过用户标识哈希截取最多 2,048 人。源域仅保留该用户群；训练、物品表、门控统计均遵守共同训练时间截点。
- 时间划分：目标域约 70% 训练、15% 验证、15% 测试，时间相同的记录不强行拆开。按既有用户、既有物品协议评估，报告丢弃覆盖率。
- 数据覆盖检查：训练前只检查用户/物品/交互数、验证与测试可评估人数及源知识覆盖。若覆盖不足，可依据这些数量调整规模，不能依据测试排序结果调整数据或配置。
- 对照：local、graph_transfer（上游模块适配）、fixed、fixed_capacity、global、user、item。均使用相同预训练和目标数据；fixed_capacity 近似匹配用户门控参数量。
- 预算：8 维表示；各域预训练 3 轮，目标融合 10 轮，每客户端 1 个本地 epoch。训练种子 2026、2027、2028，最多 2 个本地 CPU 进程，每进程 1 个计算线程。
- 固定权重：fixed 与 fixed_capacity 分别比较 gamma=0.25、0.5、1.0，每个候选均仅按验证集 NDCG@10、再按 Recall@10 选轮次与权重，并列时保留先出现的候选/轮次。global、user、item 不追加权重搜索。
- 最终测试：每方法每种子仅对选定检查点评估一次。候选为目标域完整训练物品表，屏蔽该用户训练正反馈，报告 Recall@10、NDCG@10 的三种子均值与样本标准差。
- 补充报告：有源知识用户分组、训练交互数量分组、门控变化、相对 fixed 的配对种子差值、参数量和耗时。总体结果与有源知识子群同时报告，避免遗漏大量回退为本地预测的用户。
- 流行度基线：仅按目标训练物品交互计数排序，计数相同时按物品索引排序；评估同一候选协议，作为检查训练模型是否学到有效排序的参考，不参加调参。

本轮仍为本地文件头子集实验，具有物品顺序和暖用户/暖物品选择偏差；不将它视为完整数据集实验或原论文精确复现。数据版本与跨域标识来源仍需核验，单机模拟不提供正式隐私保证。

配置文件：`../configs/local_small.json`。原始数据、派生划分、日志和检查点放在 `data/`、`runs/`；聚合结果保存在 `results/`。
