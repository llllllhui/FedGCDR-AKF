# 初步实验比较

状态：2026-10-27 已将用户或场景条件下的动态 gamma 加入研究目标，并完成上游模块接入、研究实现和小规模端到端试运行。正式效果实验尚未开展；本地 16 个品类文件已到位，正式数据来源、域组合、用户群与协议仍需核验和固定。实现与原论文的差别见 `implementation.md`，验证记录见 `../results/implementation_validation.json`。

## 首轮要回答的问题

1. 在相同数据、骨干模型和可用跨域信息下，保留独立本地预测分支并进行 FR-CSU 式融合，是否改善 FedGCDR 的推荐结果？
2. 在融合结构一致的条件下，根据用户或场景学习动态 gamma，是否优于验证集选择的固定 gamma，以及全局可学习的单一 gamma？
3. 动态权重的收益是否集中于少交互用户，是否减轻部分用户因迁移而出现的性能下降？这些均是待验证假设，不预设实验结论。

## 动态 gamma 的候选定义

- 首轮以用户级权重 `gamma(u, target_domain)` 为主；候选输入为本地用户表示、协议允许的迁移用户表示、本地训练交互统计和目标域标识。
- 当前实现每轮单独训练一个目标域模型，用户级门控已使用本地用户、扩展图用户表示和训练交互数，域条件由目标域模型本身体现；跨目标域共享门控与域嵌入尚未实现。
- 用小型可学习门控 `g_theta` 生成权重，例如 `gamma = sigmoid(g_theta(inputs))`，在训练集上与推荐目标联合学习。首轮候选范围为 `[0, 1]`，固定 gamma 与全局可学习 gamma 使用相同范围；范围和结构在最终测试前锁定。
- 保持候选加性融合：`prediction = f2(local_score + gamma * transferred_score)`，其中 `transferred_score = f1(concat(transferred_user, target_item))`。这里 gamma 调节迁移项强度，本地项系数仍为 1，不把该式称为本地与迁移预测的凸组合。
- 场景级扩展考虑 `gamma(u, item, target_domain)`，加入候选物品表示，比较同一用户面对不同物品时的权重。当前文件头样本只有评分和时间戳等四列，没有显式设备、地点或会话字段；不假设存在这些场景标签。
- 用户或物品条件变化导致的权重变化，与模型在线更新是不同设置；首轮不默认引入在线训练。
- 门控仅使用预测时可获得且协议允许使用的信息。交互数量、表示与统计不能含验证集或测试集行为；跨域信息同样遵守时间截点。缺失迁移信息时的回退规则在训练前确定。

## 比较组

1. 目标域单域模型：衡量本地推荐能力。
2. 原始 FedGCDR：保持上游协议；任何适配单独记录。
3. FedGCDR 加本地预测分支、固定 gamma 为 1：作为额外分支的对照，并单独记录参数量。
4. 固定 gamma 融合：gamma 从预先规定的候选范围中通过验证集选择，作为 FR-CSU 式融合基线。
5. 全局可学习 gamma 融合：训练一个所有用户共用的标量，区分自动学习系数与用户条件化的效果。
6. 用户级动态 gamma 融合：本轮主要候选方法。
7. 候选物品条件下的动态 gamma 融合：场景级扩展，代码和试运行已提供，正式比较仍需在数据协议固定后开展。
8. 融合消融：gamma 为零、仅迁移分支、去除本地训练统计等门控输入；对照使用相同融合骨干。

新增分支的参数量、训练轮数和调参预算应公平比较。记录门控额外参数量，设置相近参数预算的固定权重模型对照，避免将增加模型容量带来的收益全部归因于动态权重。不会仅凭融合模型优于单域模型就认定其优于 FedGCDR，也不会仅凭学出的 gamma 不同就认定动态门控有效。

## 数据与域选择

- 使用本地 `ratings-full/` 的 16 个品类 CSV 作为候选数据池；文件列表与抽样范围见 `data_inventory.md`。
- 先核验数据来源、版本和字段语义，计算文件哈希及全量用户、物品、交互、重复记录和时间范围，再统计跨域用户重叠矩阵。
- 在来源允许跨品类对齐的前提下，使用用户标识建立跨域匹配；重叠比例、对齐信息和匹配统计的交换权限均需明确。
- 根据训练数据规模、用户重叠和领域差异确定首轮一个目标域及多个源域，不依据最终测试集效果选择域组合。
- 若转为隐式反馈，评分阈值、重复交互合并、过滤规则、负采样及未见物品处理须预先固定。先确定时间划分，再基于允许的训练信息计算特征和统计，避免未来行为泄漏。

## 评估

- 固定训练、验证、测试划分；尽量采用可核验的时间划分。
- 固定候选物品集合、负采样策略和随机种子。
- 使用 NDCG@10、Recall@10 等明确实现的排序指标，报告多种子均值和离散程度。
- 按目标域训练交互数量分组，检查少交互与充分交互用户的差异。
- 比较固定、全局可学习与动态 gamma 的整体及分组排序指标，报告多种子差异与不确定性。
- 记录 gamma 的整体分布、按训练交互数量及目标域分组的分布，检查权重是否退化为近似常数或长期饱和；分布仅用于机制分析，不能替代推荐效果验证。
- 以目标域单域模型和固定 gamma 融合为参照，报告逐用户指标差值的分布及下降用户比例；仅在满足评估交互要求的用户上比较。
- 记录通信量、训练与本地适配耗时。
- 若开展新用户接入实验，明确其是否参与前期训练、源域信息是否可用，以及适配预算。

## 解释边界

固定 gamma 保留为参考基线，用户级与候选物品条件动态 gamma 已实现并通过小规模流程验证，推荐效果与创新性尚未验证。当前 `graph_transfer` 是复用上游模块的协议适配对照，不能替代原始 FedGCDR 的精确复现基线。原参考记录中的 FR-CSU gamma 仍按超参数理解，不将本项目的动态门控归因于原方法。显式收益预测、不确定性门控和多域互利约束尚未被确认为项目内容。差分隐私、上游精确复现和创新性需要分别核验，不能由代码可运行推定。
